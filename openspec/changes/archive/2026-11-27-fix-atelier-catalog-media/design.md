# Design

## Context

分类数据和筛选由 useProductList 管理；atelier 将侧栏 CategoryTree 放在主搜索区。图片分别使用列表图片回退、AtelierProductStage 和 SmartImage。现有 ProductCardStage 已实现旋转及暂停。旧本地库的商品图片路径大多没有对应上传文件。

## Goals / Non-Goals

**Goals:** 沿用共享业务状态和卡面组件，只调整 atelier 展示，保持三级路由和完整卡面可用。

**Non-Goals:** 不修改分类数据、支付流程、售价、图片地址或其他模板外观；不以伪造原图掩盖缺失文件。

## Decisions

- 根据现有分类树和选中路径构造二、三级筛选行；行首提供父级全部选项。复用现有 selectCategory 与路由恢复，不增加独立选中状态。
- 精密卡片将头像展位改为 8:5 完整封面，保留原有图片候选及坏图回退；横表移除图标展位。
- 详情头卡改为纵向大展台加信息区，保留右侧订单回执和既有 ProductCardStage，避免小头像内嵌旋转图片难以辨识。
- 结算、购物车复用 SmartImage，统一横向比例和 object-contain，手机端标题、价格可换行。
- 使用分类单测及浏览器桌面/手机验收；测试图片只经独立本地预览服务提供，不修改数据库或假冒旧上传文件。

## Risks / Trade-offs

- 图片原文件缺失 → 明确区分资源缺失与组件显示，使用可用测试图和坏图分别验收。
- 分类条名称过长 → 选项限制宽度并允许文本换行，父级切换从当前路径派生后代行。
- 卡面旋转在小屏显示不清 → 详情使用整行宽度，沿用共享暂停与减少动态效果支持。
